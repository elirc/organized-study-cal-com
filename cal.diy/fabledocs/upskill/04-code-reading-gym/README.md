# 04 · Code Reading Gym

Reading code well is the highest-leverage skill for reaching mid-level and passing interviews — most of the job and most of the loop is understanding code you didn't write. This module is deliberate practice.

1. [01-annotation-drills.md](01-annotation-drills.md) — 10 excerpts to annotate (inputs/outputs/invariants/side effects/failures).
2. [02-trace-tables.md](02-trace-tables.md) — 6 step-by-step data traces across layers.
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 10 bad-vs-better pairs tied to real repo patterns.
4. [04-review-katas.md](04-review-katas.md) — 9 fake PRs to review, graded blocking/important/optional.

Work with the files open. The rubric is always: naming the file is Basic; tracing data and naming the boundary is Solid; stating the invariant + a failure mode + the test you'd write is Strong. Strong is the interview bar.
